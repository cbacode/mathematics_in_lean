利用C++构建卷积神经网络进行手写数字图像识别
1. 利用 C++ 编写代码读入MNIST数据集
2. 自行编写卷积层、池化层以及全连接层代码完成模型的构建
3. 输出模型的训练情况相关信息并利用MATLAB将训练过程中的数据制作成图表
4. 单隐层神经网络训练后准确率达到95%，带有三层卷积层的神经网络训练后准确率达到98%
5. 在结构相同的前提下，利用C++构建的模型与利用MATLAB中的深度学习包构建的模型具有相近的准确率以及损失值
代码仓库地址：https://github.com/cbacode/DeepLearning
