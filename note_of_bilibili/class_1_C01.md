### S01

#### 1. sorry

sorry代表某个定理没有被证明完毕。

在书写证明时应当保持写sorry的习惯，尤其在将定理拆分为几个部分进行证明的过程中。

#### 2. 编译结果

编译结果通过点击右上角infoview按键获取。

### S02

#### 1. import

Mathlib中包含一些基本定理，可以通过import的方式导入一些基本概念。

Mathlib所在的路径为".\\mathematics_in_lean\\.lake\\packages\\mathlib\\Mathlib"

MIL的相关包都放在Mathlib.Tactic中，该包在MIL外部无法使用。

Mathlib中平面几何相关的包不完善。

调用的包越多，编译越慢。

包调用必须都在文件最前方，不允许在文件中间调用import命令。

#### 2. open

open可以指定文件所在的领域，在正文中可以不显式指定没有歧义的包。

若利用open命令打开的包过多，会导致定义出现歧义，此时也需要显式指定命令对应的包名。

e.g. Nat.le_add_right -> open Nat ; le_add_right

#### 3. 编译

lean文件每更改一个字符就会将被修改的字符之后的部分重新编译一次。

#### 4. check

查询check之后的指令的相关信息

#### 5. def

定义函数

#### 6. 缩进要求

: + - * / 等二元运算符两边都要有空格

, ; 后面加空格，前面不加空格(";"代表换行符，","代表且)

一行不要超过100个字符，infoview中的两个数字分别代表行数与列数(13:14代表13行14列)

每行的最后不要有空格

命题陈述时若需要换行，新行之前加4个空格或2个Tab(Tab为两个空格)

证明的新行之前加2个空格或1个Tab

#### 7. 符号

"\\->" : 推出
"\\neq" : 不等于
"rfl" : 由定义可知
"\all" : 任意
"\R" : 实数

#### 8. 定理叙述

def 命题名称 : 命题叙述 := (by) 证明
def 命题名称 := 命题叙述

theorem 定理名称 : 定理叙述 := (by) 证明
theorem 定理名称 : 命题名称 := (by) 证明

lemma 定理名称 : 定理叙述 := (by) 证明
lemma 定理名称 : 命题名称 := (by) 证明

example : 命题叙述 := (by)证明
