### S01

#### 1. type

#### 2. sets

- "\\sub" "\\ss" : 子集
- "\\cap" "\\i" : 交集
- "\\cup" "\\un" : 并集
- "univ" : 全集
- "\\empty" : 空集
- "\\in" "\\mem" : 属于
- "\\notin" : 不属于
- "\\" : 差集

使用intro或rcases时，lean会自动展开定义。

交集比并集更紧密

#### 3. simp

simp [定理] : 在尝试简化时利用定理
simp [-定理] : 在尝试简化时不利用定理

#### 4. 集合序列的交并

集合序列有可数个 : "\cup" i, A i
集合序列有不可数个 : "\cup\0" A

### S02

#### 1. 像和原像

f : "\\alpha -> \\beta"
u "\\in" "\\alpha"
v "\\in" "\\beta"

"f \\-1' u" : u的原像
"f '' v" : v的像

"f '' v" : rcases "\\<" x, xs, xeq "\\>"
({y | \\exist x, x \\in s \\and f x = y})

"f \\-1' u"
({x | f x \in u})
